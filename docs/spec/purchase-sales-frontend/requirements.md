# 仕入・売上管理フロントエンド 要件定義

## 背景

fasse_infra で構築した REST API を利用し、Flutter から仕入・売上管理のデータを操作するフロントエンドを提供する。

## 目的

- 仕入・売上・マスタデータを画面から閲覧・登録・更新・削除できるようにする
- API のベース URL を環境ごとに切り替えられるようにする
- 将来的な Spring Boot への移行を見据えた API 抽象化を行う

## スコープ

- マスタデータ画面: 品目・仕入先・メニュー
- 伝票画面: 仕入伝票・売上伝票
- API 接続設定: stg / prod 用の基底 URL 管理
- エラー表示とローディング状態
- 初期画面の主要機能選択 UI

## 画面仕様

- Flutter 起動時の初期画面では、3つの主要ボタンを縦方向に並べて表示する
- 表示順は上から「仕入伝票」「売上伝票」「マスタメンテナンス」とする
- 「マスタメンテナンス」ボタン押下時に、さらに 3 つのマスタ操作ボタンを縦方向に表示する
- 表示順は上から「品目」「仕入先」「メニュー」とする
- 仕入伝票・売上伝票・各マスタの画面では、対象 domain のデータ一覧を表示し、追加・変更・削除ができるようにする
- WebAPI で実装済みの各機能は、Flutter 側からすべて利用できるようにする
- 画面サイズが小さい場合でも操作しやすいよう、余白・ボタンサイズ・スクロール対応を適切に行う

## スコープ外

- 認証・認可
- 複雑な集計・レポート画面
- オフライン同期

## 受け入れ条件

- API のベース URL を環境変数で切り替えられる
- 一覧・詳細・登録・更新・削除の基本フローが動作する
- API エラー時にユーザーへ分かりやすいメッセージを表示できる
- 初期画面で 3 つの主要ボタンが縦に並ぶ
- マスタメンテナンスから 3 つのマスタボタンが縦に並ぶ
- 左上の戻るボタンで直前の画面へ戻れる
- 仕様書と実装が対応づけられている
